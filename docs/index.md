# Assessing the Data-Centric Robustness of a Crack Tip Detection Model through Artificial Data Pollution

This repository provides the experimental framework used in the study
_Assessing the Data-Centric Robustness of a Crack Tip Detection Model through Artificial Data Pollution_.

The objective of the work is to evaluate the robustness of crack-tip segmentation methods
under controlled data degradation scenarios. The CrackMNIST dataset is subjected to
parameterized perturbations (noise, blur, and occlusions), and the performance of a U-Net
segmentation model is assessed under varying degrees of input quality.

Please refer to the [README](https://github.com/DLR-KI/crack-tip-localization) for
installation and usage instructions.
